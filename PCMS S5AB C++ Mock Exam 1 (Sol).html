三大核心二進位數學性質
  • 全 1 結構：2ᵏ - 1 的二進位表示為連續 k 個 1。
  • 高位包含減法：若 A 的二進位包含 B 的所有 1 位，則 A ^ B = A - B（相同位 1 ^ 1 = 0）。
  • 互不重疊加法：若 X 與 Y 沒有任何一位同時為 1，則 X ^ Y = X + Y（0 ^ bit = bit）。

輸入範圍：1 ≤ n ≤ 10000。當 n = 10000 時，n³ = 10¹² 次運算在 1 秒內必定超時 (TLE)，因此必須推導數學閉式公式。

數學本質：求 i + j + k = n 的正整數解組數

迴圈變數 i, j, k 均從 1 枚舉到 n（且滿足 i+j+k=n 時必有 i,j,k ≤ n-2 < n，上界 n 完全覆蓋所有解）。

方法一（固定 i 累加）：
當固定 i（1 ≤ i ≤ n - 2）時，j + k = n - i 的正整數解有 n - i - 1 組：
cnt = (n - 2) + (n - 3) + ... + 2 + 1 = (n - 1)(n - 2) / 2
方法二（組合插板法）：將 n 個球排成一列，在 n - 1 個間隙插入 2 塊板分成 3 份，解數為 C(n - 1, 2) = (n - 1)(n - 2) / 2。
小樣例展開驗證（以 n = 5 為例，公式得 4×3/2 = 6 組）
固定 i 剩餘方程 j + k = 5 - i 合法三元組 (i, j, k) 解數
i = 1 j + k = 4 (1,1,3), (1,2,2), (1,3,1) 3 組
i = 2 j + k = 3 (2,1,2), (2,2,1) 2 組
i = 3 j + k = 2 (3,1,1) 1 組
i ≥ 4 j + k ≤ 1（無正整數解） 無 合計 6 組

第 22 題（5分）：Solve1 中 cnt 的最大值 MAX 答案：B

對 f(m) = nm + m - m² 進行二次函數配方法：

f(m) = -[ m - (n + 1)/2 ]² + (n + 1)² / 4
n 的奇偶性 整數最優取點 m 代入計算最大值 MAX
情況 1：n 為奇數
(例 n=5, n+1=6)		 m = (n + 1) / 2
(頂點恰好為整數)		 MAX = (n + 1)² / 4
(例 6²/4 = 9，整除)
情況 2：n 為偶數
(例 n=4, n+1=5)		 m = n/2 或 (n+2)/2
(距對稱軸最近整數)		 MAX = n(n+2)/4 = [(n+1)² - 1] / 4
(例 4×6/4 = 6 = ⌊25/4⌋)

奇偶統一結論：當 n 為偶數時，(n+1)² 必為奇數（除以 4 餘 1），因此 [(n+1)² - 1] / 4 在整數除法中恰好等於向下取整 ⌊(n+1)² / 4⌋。故無論奇偶皆為 ⌊(n+1)² / 4⌋，選 B。

第 23 題 ①：二分上界 r 答案：D (`100`)

題目保證所有輸入整數不超過 100，若長度 L > 100 一段也切不出，故最大答案上界為 100（選 D）。

第 24 題 ②：中點計算 mid 答案：C (`(l + r + 1) >> 1`)

求最大可行值且合法時執行 l = mid，必須使用 (l + r + 1) >> 1 向上取整，防止相鄰兩數時死循環（選 C）。

第 25 題 ③：單根葱切出段數 答案：A (`a[i] / mid`)

每根長度 a[i] 的葱切成每段 mid，C++ 整數除法 a[i] / mid 精確求出向下取整的段數（選 A）。

第 26 題 ④：滿足條件分支 答案：A (`if (cnt >= k) l = mid;`)

題目要求切出「至少 k 段」，即 cnt >= k（必須含等號）；滿足時保留 mid 並向右探索，令 l = mid（選 A）。

第 27 題 ⑤：不滿足條件右界 答案：A (`mid - 1`)

當 cnt < k 時，mid 過長無法切出足夠段數，必須徹底排除 mid，將右邊界更新為 mid - 1（選 A）。

第 28 題 ①：試除質因子範圍 答案：D (`for (int i = 2; i * i <= n; i++)`)

試除必須從最小素數 2 開始（從 1 開始會無窮整除），且包含等號 i * i <= n（如平方數 4 = 2²），選 D。

第 29 題 ②：除盡相同質因子 答案：C (`while (tmp % i == 0) cnt[i]++, tmp /= i;`)

單個數可能含多個相同質因子（如 12 = 2²×3），必須用 while 除盡；且應修改副本 tmp 而非破壞外層迴圈變數 x，選 C。

第 30 題 ③：記錄剩餘質因子 答案：B (`cnt[tmp]++`)

試除所有 ≤ √n 因子後，若剩餘 tmp > 1 則它必為大於 √n 的唯一質因子；若 tmp == 1 執行 cnt[1]++ 亦不影響後續從 2 開始的輸出，選 B。

第 31 題 ④：輸出起始質因子 答案：B (`2`)

1 不是素數，最小質因數為 2，故從 i = 2 開始由小到大遍歷輸出（合數位置 cnt[i] 恆為 0），選 B。

第 32 題 ⑤：輸出對應個數質因子 答案：D (`while (cnt[i]--) cout << i << ' ';`)

需輸出 cnt[i] 次質因子本身 i（注意 A 誤輸出次數 cnt[i]，C 誤輸出序號 j），選 D。
